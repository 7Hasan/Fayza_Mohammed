# صدقة جارية عن روح فايزة محمد

نسخة مستقلة من موقع الصدقة الجارية، مهيأة لروح فايزة محمد رحمها الله، مع أيقونة امرأة محجبة بدل الصورة الشخصية.

**الموقع بعد تفعيل GitHub Pages:** https://7hasan.github.io/Faysa_Mohammed/

## الملفات
- `index.html` — الصفحة الرئيسية.
- `style.css` — التصميم والألوان.
- `script.js` — الأدعية، التسبيح، إحصائيات الزيارات، وطلب التثبيت.
- `manifest.webmanifest` — إعدادات التثبيت كتطبيق.
- `sw.js` — التخزين المؤقت والعمل دون اتصال.
- `icon.svg` — أيقونة المرأة المحجبة المستخدمة للموقع والتطبيق.
- `diagnostics.html` — اختبار اتصال الموقع بخدمة Google Apps Script.
- `Code.gs` — كود Google Apps Script المخصص لجدول فايزة.

## ربط Google Sheets (مطلوب قبل تشغيل سجل الدعاء والعداد)
1. افتح جدول فايزة: https://docs.google.com/spreadsheets/d/1Ta49DYhNik60CSgYCL8vzzvcNqqPx2VzQqa2fkMl1Sc/edit
2. اختر **الإضافات (Extensions) ← Apps Script**.
3. انسخ محتوى `Code.gs` من هذا المستودع إلى محرر Apps Script واحفظ.
4. اختر **Deploy ← New deployment**، ثم نوع النشر **Web app**.
5. اجعل **Execute as: Me** و **Who has access: Anyone**، ثم Deploy ووافق على الأذونات.
6. انسخ رابط النشر الذي ينتهي بـ `/exec` وأرسله لي لأضيفه إلى ملفي `script.js` و`diagnostics.html`.

### بنية الأوراق
- يستخدم سجل الدعاء تبويب `الورقة1` بالأعمدة: رقم الدعاء، نص الدعاء، اسم الداعي، تاريخ الإرسال، حالة الدعاء.
- ينشئ الكود تبويب `إحصائيات الزوار` تلقائيًا، ويكتب إجمالي الزيارات في الخلية `C2`.
- تظهر الأدعية للزوار بعد تغيير حالة الدعاء إلى `منشور` أو `معتمد` في العمود E.
- يُحفظ الدعاء الجديد بحالة `قيد المراجعة` حتى تتم مراجعته.

## الخصوصية
- لا يسجل عداد الزيارات أسماء أو أرقامًا أو عناوين IP.
- يسجل زيارة واحدة لكل متصفح في اليوم بتوقيت عدن، ويعرض الإجمالي فقط عند الضغط على أيقونة العين.
- اسم الداعي اختياري، ويرتبط بالدعاء الذي يرسله فقط.
- بيانات هذا الموقع مستقلة بالكامل عن أي موقع آخر، وله معرّف Google Sheet مخصص.

## النشر
فعّل GitHub Pages من إعدادات المستودع على الفرع `main` والمجلد `/ (root)`.
